## 2. 사이트맵 (안)

```
홈
├─ 브랜드 스토리 (청오 이야기 / 발아 기술 / 농장과 시설 / 인증)
├─ 쇼핑 (들기름 / 참기름 / 곡물·분말 / 선물세트 / 정기배송)
│   └─ 상품 상세 (영상, 영양정보, 리뷰, Q&A)
├─ 장바구니 → 주문/결제 → 주문완료
├─ 마이페이지 (주문내역, 배송조회, 취소·반품, 리뷰, 적립금, 쿠폰, 배송지)
├─ 고객센터 (공지, FAQ, 1:1 문의, 대량·B2B 구매 문의)
└─ 관리자 /admin (별도 로그인)
```

## 3. 기능 명세

### 3.1 소비자 (구매)
- 회원가입: 이메일, 카카오, 네이버. 비회원 주문 지원.
- 상품: 목록, 필터(카테고리·가격), 검색, 옵션(용량), 재고 표시.
- 장바구니, 찜, 최근 본 상품.
- 결제: 토스페이먼츠 또는 포트원 (카드, 간편결제, 가상계좌).
- 주문조회, 배송추적(택배사 API), 취소·반품·교환 신청.
- 리뷰(포토), 적립금, 쿠폰.

### 3.2 판매 (범위 확인 필요)
- A안: 청오 직판. 관리자가 상품을 등록하고 판매.
- B안: 입점 판매자(농가·제휴사) 다수가 판매하는 마켓플레이스. 정산 기능 필요, 개발량 약 2배.
- C안: B2B 도매(식당·납품처) 전용 가격과 견적 요청.

### 3.3 관리자
- 대시보드: 오늘 매출, 주문 수, 신규 회원, 재고 부족 알림.
- 상품: 등록·수정, 옵션, 재고, 노출 순서, 이미지 업로드.
- 주문: 상태 변경(결제완료→배송준비→배송중→완료), 송장 일괄 등록(엑셀), 취소·환불 처리.
- 회원: 조회, 등급, 적립금 지급.
- 마케팅: 쿠폰, 배너, 팝업, 공지.
- 콘텐츠: 브랜드 스토리, FAQ 편집.
- 권한: 최고관리자 / 운영자 분리, 관리자 행동 로그.

## 4. 기술 스택

| 영역 | 선택 | 이유 |
|---|---|---|
| 프레임워크 | Next.js 15 (App Router) + TypeScript | 프론트·백엔드·관리자를 한 저장소에서 개발 |
| UI | Tailwind CSS + shadcn/ui | 빠른 제작, 일관된 디자인 시스템 |
| DB | PostgreSQL (Supabase) + Drizzle ORM | 주문·재고 트랜잭션, 무료 요금제로 시작 |
| 인증 | Auth.js 또는 Supabase Auth (카카오·네이버 OAuth) | 소셜 로그인 |
| 파일 | Supabase Storage | 상품 이미지 |
| 결제 | 토스페이먼츠 (또는 포트원) | 국내 간편결제 대부분 지원 |
| 배포 | Vercel (프론트) + Supabase (DB) | Git push 하면 자동 배포 |
| 도메인 | 기존 `chung-oh.co.kr` 유지, DNS만 변경 | 검색 순위 유지 |
| 모니터링 | Vercel Analytics, Sentry | 오류 추적 |

## 5. 개인정보·법적 요건 (개인정보 민감)

- 개인정보보호법: 개인정보처리방침, 수집 항목 최소화, 동의 분리(필수/선택/마케팅).
- 저장: 전화번호·주소는 DB 컬럼 암호화(AES-256). 비밀번호는 bcrypt 또는 소셜 로그인으로 미보관.
- 카드정보는 저장하지 않음. PG사가 처리.
- 전자상거래법: 푸터에 상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 주소, 연락처 표시. 청약철회 안내.
- 주문 기록 5년, 소비자 불만 기록 3년 보관.
- 식품 표시·광고법: "질병 예방·치료" 표현 금지. 상세페이지 문구 검수.
- 관리자: 2단계 인증, IP 제한(선택), 접근 로그.
- HTTPS 전 구간, Supabase Row Level Security.

## 6. 제작부터 배포까지 단계

| 단계 | 기간 | 산출물 |
|---|---|---|
| 1. 기획 확정 | 1주 | 이 문서 확정, 사이트맵, 기능 목록 |
| 2. 디자인 | 1~2주 | 무드보드, 메인·상품상세·결제 시안 (Figma 또는 코드 시안) |
| 3. 영업용 데모 | 1주 | 메인·브랜드·상품목록·상세 화면을 Vercel에 배포한 링크 |
| 4. 계약 | - | 견적, 범위, 유지보수 조건 |
| 5. 개발 1차 | 3~4주 | 회원, 상품, 장바구니, 결제, 주문, 관리자 기본 |
| 6. 개발 2차 | 2주 | 리뷰, 쿠폰, 적립금, 배송추적, 통계 |
| 7. 테스트 | 1주 | 결제 테스트 모드, 모바일 기기 테스트, 보안 점검 |
| 8. PG 심사·오픈 | 1~2주 | PG 계약 심사, 도메인 연결, 기존 URL 리디렉션 |
| 9. 운영 | 매월 | 유지보수, 백업, 콘텐츠 업데이트 |

### 배포 절차 상세
1. GitHub 저장소에 코드 push.
2. Supabase 프로젝트 생성 → DB 마이그레이션 실행.
3. Vercel에서 GitHub 저장소 import → 환경변수(DB URL, PG 키, OAuth 키) 등록.
4. `main` 브랜치 push 시 자동 배포. PR마다 미리보기 URL 생성.
5. 도메인 업체(가비아 등)에서 `chung-oh.co.kr` DNS를 Vercel로 연결. SSL 자동 발급.
6. 기존 게시판 URL을 새 페이지로 301 리디렉션.
7. 네이버 서치어드바이저, 구글 서치콘솔에 사이트맵 제출.

## 7. 영업 전략 (판매 제안)

- 대표에게 "말"보다 "작동하는 데모 링크"를 먼저 보여줌. 기존 사이트와 새 사이트를 휴대폰에서 나란히 비교.
- 비교 대상: 카페24·아임웹 같은 임대형 쇼핑몰. 자체 개발의 장점은 월 수수료 없음, 디자인 자유, 데이터 소유. 단점은 초기 비용과 유지보수 의존.
- 견적 구성(opinion): 제작비 일시불 + 월 유지보수비. 국내 중소 자사몰 외주 시세는 대략 500만~2,000만 원 범위로 알려짐. 계약 전 지역 시세 재확인 필요.
- 운영비 예상: Vercel Pro 월 $20, Supabase Pro 월 $25, PG 수수료 결제액의 약 3%.
